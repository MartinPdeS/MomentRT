Python class reference#

All dimensional arguments require quantities from MomentRT.ureg. Array shapes and physical conventions are described for each class. Plotting methods require the relevant optional visualization extra.

Materials and sample geometry#

class Material(*, absorption, reduced_scattering, refractive_index, anisotropy=None, phase_function='henyey_greenstein')[source]#

Bases: object

Wavelength-independent optical coefficients for moment models.

Parameters:

  • absorption (pint.Quantity) – Nonnegative absorption coefficient, with inverse-length units.

  • reduced_scattering (pint.Quantity) – Positive reduced scattering coefficient, with inverse-length units.

  • refractive_index (float) – Positive dimensionless refractive index, supplied without units.

  • anisotropy (float or None, optional) – Mean scattering cosine in (-1, 1), supplied without units. Required by SP3, where it selects Henyey–Greenstein scattering; P1 does not use it.

  • phase_function ({'henyey_greenstein'}, optional) – Scattering phase-function model used by SP3. Defaults to 'henyey_greenstein'; P1 does not use it.

Notes

The diffusion length coefficient is D = 1 / (3 * (absorption + reduced_scattering)). No wavelength dependence is inferred.

Examples

>>> import MomentRT
>>> ureg = MomentRT.ureg
>>> tissue = MomentRT.Material(
...     absorption=0.1 / ureg.millimeter,
...     reduced_scattering=1.0 / ureg.millimeter,
...     refractive_index=1.4,
... )

class SpectralMaterial(*, wavelengths, absorption, reduced_scattering, refractive_index, anisotropy=None, phase_function='henyey_greenstein')[source]#

Bases: object

Tabulated optical coefficients with linear interpolation and no extrapolation.

wavelengths must increase strictly. Coefficient arrays have the same shape. refractive_index is a positive plain scalar or an array on the same grid.

Parameters:

  • wavelengths (pint.Quantity) – Strictly increasing one-dimensional wavelength grid with at least two positive entries and length units.

  • absorption (pint.Quantity) – Nonnegative absorption values with inverse-length units, matching the wavelength grid shape.

  • reduced_scattering (pint.Quantity) – Positive reduced scattering values with inverse-length units, matching the wavelength grid shape.

  • refractive_index (float or array_like of float) – Positive plain scalar or vector matching the wavelength grid. Dimensionless quantities are not accepted.

  • anisotropy (float or array_like of float or None, optional) – Plain scalar or wavelength-grid vector of mean scattering cosines in (-1, 1). Interpolated linearly; required for SP3, unused by P1.

  • phase_function ({'henyey_greenstein'}, optional) – SP3 scattering phase-function model, fixed across the wavelength table.

class SurfaceDetector(*, face, position, radius, collection_axis, acceptance_angle)[source]#

Bases: object

Circular aperture in a sample face with a cone of accepted outgoing rays.

collection_axis points along collected ray propagation, out of the sample. The aperture lies in the configured face even when the collection axis is tilted. acceptance_angle is the cone half-angle, with explicit angular units. This is a passive contact measurement with Lambertian escaping radiance; it does not alter the transport boundary or model refraction and lenses.

Parameters:

  • face ({'x_min', 'x_max', 'y_min', 'y_max', 'z_min', 'z_max'}) – Axis-aligned sample face; min and max refer to outward boundaries.

  • position (pint.Quantity) – Absolute Cartesian position, shape (3,), with length units.

  • radius (pint.Quantity) – Positive scalar radius with length units.

  • collection_axis (array_like of float, shape (3,)) – Nonzero dimensionless direction along accepted outgoing rays. It is normalized internally and must point into the outward hemisphere.

  • acceptance_angle (pint.Quantity) – Acceptance-cone half-angle, from 0 to 90 degrees, with angular units.

Notes

This is a passive contact measurement assuming Lambertian escaping radiance. It does not change the transport boundary or model lenses, refraction, or angle-resolved Fresnel transmission. For a cone wholly inside the outward hemisphere, the accepted fraction is cos(tilt) * sin(acceptance_angle)**2.

class RobinBoundary(*, effective_reflectance)[source]#

Bases: object

Diffuse internal reflection with an explicitly supplied effective reflectance.

This is a partial-current coefficient, not normal-incidence Fresnel R. No refractive-index-to-reflectance approximation is selected implicitly. With R=effective_reflectance, beta=(1-R)/(2(1+R)) and outward net current J.n = beta Phi - 2 I_in/(1+R). I_in is incoming diffuse partial current already coupled into the sample (W/m^2).

Parameters:

class Diffusion(*, boundaries)[source]#

Bases: object

Steady-state P1 diffusion with linear tetrahedral finite elements.

Geometry preparation is scoped to a solve or wavelength sweep. No persistent cache survives changes to a sample, source, mesh, or boundary configuration.

Parameters:

boundaries (mapping of str to RobinBoundary or ReflectingBoundary) – Conditions for exactly all six sample faces. Reflecting faces cannot carry illumination.

Notes

The steady-state P1 equation is -div(D grad(Phi)) + mu_a Phi = 0, with J = -D grad(Phi). Linear tetrahedra use centroid-sampled material coefficients. Fluence is continuous across interfaces; internal refractive-index jumps are unsupported. Footprint and unaligned interface errors require mesh refinement. Geometry preparation is scoped to a solve or sweep, with no persistent cache.

class SP3(*, boundaries)[source]#

Bases: object

Solve two coupled simplified P3 moments using tetrahedral elements.

Parameters:

boundaries (mapping of str to RobinBoundary or ReflectingBoundary) – Conditions on all six faces. Robin boundaries must have zero effective reflectance, corresponding to a matched-index vacuum boundary.

Notes

Each material must supply its own anisotropy. The solver assumes the Henyey–Greenstein phase function and uses its higher angular moments. Illumination is isotropic over the incoming hemisphere. Fluence is the zeroth moment, not the first composite unknown. The implementation assumes continuous composite moments across internal interfaces and rejects index jumps. SP3 is an approximation, and agreement with SP3 slab references does not establish accuracy against radiative transfer for a particular sensor.

Full steady-state three-dimensional P3 transport on a finite sample.

Parameters:

boundaries (mapping of str to RobinBoundary) – Six matched-index faces with zero effective reflectance. Reflecting and index-mismatched boundaries are not implemented by this P3 solver.

Notes

Six even harmonics are solved with linear tetrahedral FEM; ten odd harmonics are reconstructed elementwise. Materials require anisotropy and use the Henyey–Greenstein phase function. Illumination is isotropic over the incoming hemisphere. P3 is an angular approximation and requires validation for the intended configuration.

Solve wavelengths in supplied order without mutating this configuration.

optical_power may be a scalar or a same-length vector of powers. When omitted, every solve uses the configured source’s optical_power. This is a set of monochromatic solves, not broadband spectral integration.

Parameters:

  • optical_power (pint.Quantity or None, optional) – Positive scalar power or vector matching wavelengths. None retains the configured source power for every monochromatic solve. Default is None.

Returns:

Notes

These are independent monochromatic powers, not a broadband spectral integral. Finite sweeps reuse geometry, material labels, source footprint, and boundary quadrature once per call. Each wavelength gets a new bulk operator and sparse factorization.

Bases: object

Detector signals and footprint sampling on successively refined meshes.

Parameters:

  • results (sequence of SimulationResult or None) – Per-level solutions; None records an unresolved source footprint.

  • detectors (mapping of str to SurfaceDetector) – Named passive contact detectors.

  • source_geometric_area (pint.Quantity) – Exact source footprint area, with area units.

  • tetrahedron_counts (numpy.ndarray of int) – Number of tetrahedra at each refinement level.

  • source_area_relative_error (numpy.ndarray of float) – Absolute relative errors against the exact source footprint area.

  • detector_power (dict of str to pint.Quantity) – Per-detector collected power vectors in watts. Unavailable powers are NaN.

  • detector_sampled_area (dict of str to pint.Quantity) – Per-detector sampled aperture areas in square meters. Unsampled apertures have zero sampled area; unresolved sources produce NaN.

  • detector_geometric_area (dict of str to pint.Quantity) – Exact aperture area for each detector.

  • detector_area_relative_error (dict of str to numpy.ndarray) – Absolute relative aperture-area errors at each mesh level.

  • power_relative_change (dict of str to numpy.ndarray) – Relative power differences against the preceding level. The first difference and unavailable values are NaN.

  • power_relative_to_finest (dict of str to numpy.ndarray) – Relative power differences against the finest level; unavailable values are NaN.

  • meets_tolerances (numpy.ndarray of bool) – Per-level power, area, and resolution checks.

  • stable_refinements (numpy.ndarray of int) – Number of consecutive passing refinements ending at each level.

  • recommended_index (int or None) – Index of the recommended mesh; None if the final sequence fails.

Notes

Only a stable final sequence can support a recommendation. Sampled source and detector areas must approximate their exact geometric areas, and powers must meet adjacent-level and finest-level tolerances. Unresolved levels and negative fields remain visible; passing these checks is not proof of accuracy of the P1 approximation.
