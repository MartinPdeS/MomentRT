MomentRT visual identity
========================

The symbol combines a faceted sample volume, nested fluence contours, and a
warm optical source. The contours are an abstract identity mark, not a
simulation result. The wordmark uses outlined lettering and has no external
font dependency.

Assets
------

* ``logo.svg``: full wordmark with a transparent background. Its lettering
  follows the browser's preferred color scheme; this is the README asset.
* ``logo-light.svg`` and ``logo-dark.svg``: explicit theme variants selected
  by the Sphinx theme switcher.
* ``logo.png`` and ``logo-dark.png``: transparent PNG exports at 1828 by 512
  pixels for presentations and other applications.
* ``icon.svg`` and ``icon.png``: standalone symbol, with a 512-pixel PNG export.
* ``favicon.svg`` and ``favicon.png``: simplified symbol with heavier contours
  and a larger source point for small displays.
* ``favicon.ico``: browser favicon with 16, 24, 32, 48, 64, 128, and 256-pixel
  representations. Sphinx uses this file for its browser tab icon.

The SVG files are editable vector originals. Export them on a transparent
background, preserving their viewBox proportions. Use the simplified favicon
artwork for small icons instead of scaling down the detailed sample mesh.
