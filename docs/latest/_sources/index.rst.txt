MomentRT
========

Deterministic light transport using angular-moment methods.

MomentRT provides two steady-state P1 diffusion models: an analytical
infinite-medium Green function and a finite-sample linear finite-element
solver. This guide explains their equations, assumptions, workflow, and
visualization tools. It also distinguishes implemented behavior from features
that remain outside the package's scope.
